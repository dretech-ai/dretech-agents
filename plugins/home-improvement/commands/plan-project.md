Use the home-improvement skill to plan a project.

Project: $ARGUMENTS
If this names an existing file in `home/projects/`, revisit that plan. If it
describes a project, start the project interview with it. If nothing was
given, show the top of the backlog and ask which project to plan.

If `home/profile.md` doesn't exist, tell the user to run `/init-home` first
and stop.

Follow the skill's project workflow end to end: load state (import anything
in `home/inbox/` first), surface urgent items, need vs. want, search, compare
estimates, financial impact with value & tax, write
`home/projects/YYYY-MM-<property>-<slug>.md`, and update the backlog. Never
hire, sign, or pay anyone, and never write account numbers or street
addresses.
