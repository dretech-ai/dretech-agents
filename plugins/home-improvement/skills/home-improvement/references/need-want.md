# Need vs. want, and the backlog

Every project gets scored, classified, and ranked into `home/backlog.md`.
Score from the facts in `systems.md`, inspection reports, and what the user
said — not from how much the user wants it.

## Score (0–3 each)

| Factor | 0 | 1 | 2 | 3 |
|--------|---|---|---|---|
| **Safety / code** | none | minor code issue | hazard if left | active hazard (gas, electrical, structural, fall, CO) |
| **Damage prevention** | none | slows wear | prevents likely damage | active leak, rot, settling, or pest damage |
| **System end of life** | < 60% of life used | 60–90% | 90–110% | past expected life or failing |
| **Efficiency payback** | none | > 15 yrs | 7–15 yrs | < 7 yrs |
| **Function / accessibility** | none | convenience | daily friction | blocks use (no heat, unusable bath, aging-in-place need) |
| **Resale value** | none or negative | low recoup | typical recoup | fixes a defect a buyer's inspector would flag |
| **Comfort / aesthetic** | 0 | 1 | 2 | 3 |

- **Resale** counts only if the user plans to sell or refinance within ~5
  years (or it's a rental, where it counts toward rent and vacancy).
- **Efficiency payback** = net cost after rebates ÷ annual savings. Say where
  the savings estimate came from; mark it missing if there isn't one.

## Classify

Use the first rule that matches:

1. **Need now** — Safety/code = 3, or Damage prevention = 3, or a system is
   failing (no heat, no water, active leak), or an insurer/lender/HOA/city
   requires it by a date.
2. **Need soon (≤ 2 yrs)** — Safety, Damage, or End-of-life ≥ 2.
3. **Want — high value** — Efficiency payback ≥ 2, or Function ≥ 2, or
   Resale ≥ 2 with a sale planned within 5 years.
4. **Want** — everything else.

A project can mix both: a bathroom remodel that fixes a leaking shower pan is
a need for the pan and a want for the rest. Split the cost into **need
portion** and **want portion** and say so in the plan.

## Cost of deferral

Every Need gets one line: what happens if it waits 1–2 years, and the rough
cost then. Examples: roof leak → decking and drywall repair on top of the
roof; failing water heater → flood damage and emergency pricing; old panel →
insurance surcharge or refusal. Source ranges where you can; mark estimates
as estimates.

## Rank the backlog

1. Class: Need now → Need soon → Want — high value → Want.
2. Within a class: higher cost of deferral first, then higher total score
   per $1,000 of adjusted cost.
3. **Sequence against cash:** walk the list in order, cumulative cost against
   the cash available above the emergency fund (see
   [finance-link.md](finance-link.md)) and the replacement forecast in each
   property's `systems.md`. Mark the point where cash runs out; items after
   it get a target year, not a "now."
4. **Bundle** where it saves money or disruption: same trade, same area of
   the house, or a dependency (do the roof before solar; electrical panel
   before a heat pump or EV charger; plumbing before tile). Note bundles in
   the backlog.
5. **Seasonality:** exterior work, HVAC, and roofing have better pricing and
   availability off-season. Note the best window.

## Push back

- A Want ahead of an open Need on the same property: say so before planning
  it, and show what the Need costs if deferred.
- A Want that would drop cash below the emergency fund: verdict is **Don't**
  until the Need list is funded.
- A "need" the user calls urgent that scores low: say so, and ask what's
  driving it (sometimes it's a fact you don't have yet — a lender or insurer
  requirement).
